# Asset provenance

- `public/images/paragon-home-desktop.webp`, `paragon-home-mobile.webp`, `paragon-thumbnail.webp`: still captures of this project's current Paragon prototype renderer, exported by `scripts/capture-home-art.mjs`. The source is a paused, fully lit scene with a fixed wide rear camera and no overlays or video footage. Desktop is 1920 × 1080, mobile is a 780 × 1200 portrait crop, thumbnail is 600 × 340. These are reconstruction images, not photographs of the actual venue. Coming Soon cards use CSS placeholders rather than invented venue images. The visual menu layout is inspired by the user-supplied BingeBrowse reference; no assets were copied from that site.

- `public/images/*.svg`: original VANTAGE architectural/cinema illustrations generated by `scripts/create-art.mjs` for this project. They depict no verified real venue. Each directory image and the hero are labeled as illustrations in the interface.
- `public/media/vantage-demo.mp4`: original eight-second calibration animation generated by `scripts/create-demo.py`. Includes a moving orb, perspective grid, border, timer, and quiet synthesized 220 Hz tone. No film footage, music, or downloaded media is included.
- `public/media/Infinite Worlds.mp4`: video placed in the project by the user for the Paragon simulator. Local inspection found H.264 video at 1546 × 1080 pixels (about 1.4315:1), 24 fps, with AAC stereo audio; duration about 65 seconds. It is included when building the site.
- Icons: Lucide, ISC license, installed through `lucide-react`.
- Paragon charcoal carpet weave, neutral black acoustic foam sheets with subtle seams/creases/pores, independent blue light-wash masks, cyan strip halos, green EXIT sign and radial light halos: original procedural canvas textures generated at runtime in `src/simulator/proceduralTextures.js`. The appearance is inspired by user-supplied photographs, including `557603128_1212139634281126_6891239328485045704_n.jpg` supplied on 13 October 2026; no photograph, watermark, venue logo or downloaded texture is included in public assets. Rounded chairs, cup holders, doors, tall light strips and rear sconces are code-generated geometry. VP has no tables.
- Typography: Prompt for headings and primary text, Google Sans for small text and notes, served by Google Fonts with `display=swap` and a sans-serif fallback. SIL Open Font License; see [Prompt](https://github.com/google/fonts/tree/main/ofl/prompt) and [Google Sans](https://github.com/googlefonts/googlesans). Loading requires a network connection; the interface remains usable with the fallback font.
- Branch names identify third-party venues. This independent prototype has no affiliation with those venues or IMAX. No third-party logos are used.

The simulator plays each auditorium's configured static video URL; there is no browser file-upload or source-replacement UI.
